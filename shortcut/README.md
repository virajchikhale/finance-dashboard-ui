# Shortcut files

- `add-expense.plist`: the "Add Expense" Apple Shortcut as readable XML, with `YOUR_WEB_APP_URL` and `YOUR_WRITE_KEY` as placeholders.
- `make_shortcut.py`: fills in your URL and WRITE_KEY and writes the file to sign.

Setup, signing and editing: [docs/shortcut.md](../docs/shortcut.md).
